# Changelog

## 0.1.0

Primeira versão: componente React com Lista/Grid compacto, busca offline de cidades e seleção de aeroportos/IATA, conversão por IANA/Intl, indicador do instante atual, cores dia/noite, adição/exclusão, reordenação por mouse/toque/teclado e persistência configurável no localStorage. Distribuição ESM/CommonJS com tipos TypeScript e CSS separado.
